# Testing And Ops

本文件集中说明验证策略、项目结构与代理执行时的额外注意事项。

## 项目结构

```text
fileflowbridge/
├── bridge/                    # 桥接服务器
│   ├── main.go
│   └── static/
│       └── index.html
├── provider/                  # 文件提供者客户端
│   └── main.go
├── README.md                  # 用户文档
├── DEVELOPMENT.md             # 开发环境说明
└── docs/agents/               # 代理拆分文档
```

## 验证策略

项目目前没有正式测试框架，默认采用定向构建和手动验证：

1. 运行桥接服务器
2. 使用提供者上传文件
3. 通过 HTTP 端点下载文件
4. 检查日志是否有错误

若改动影响构建、配置或桥接链路，至少运行相关 `go build`；若改动影响运行时行为，再补手动链路验证。

## 代理注意事项

- 流式传输链路优先保证内存效率
- 网络可靠性和错误处理是关键要求
- 安全令牌生成不能退化为非加密随机源
- 修改代码时保留中文注释风格
- 性能监控和统计相关逻辑属于重要功能，避免误删
- 生产环境需要考虑日志轮转，避免日志文件无限增长
